## 3. 流程

1. Linux 侧 stage 0034 u-boot.bin（padded 0x80000）：copy 0.23 s、erase 0.86 s、write 0.38 s、readback 0.24 s、sync 0.17 s
2. SSH reboot -> flash E4 U-Boot banner g30dca5f54503 -> 停 autoboot -> version gate
3. mtd read spi-nand0 0x47F00000 0x3F00000 0x80000；crc32 0x47F00000 0x59530 = 0x9f2b707d
4. go 0x47F00000 -> banner g1673d5c89c7b -> 停 autoboot -> version gate
5. e2631rescue 作为第一条网络命令（此前 commands 只有 version / mtd read / crc32 / version）
6. PHY 自协商 done、lan1 up；GET /、GET /status、POST /flash?mode=validate
7. Ctrl-C -> left rescue；e2631boot -> Linux；SSH postcheck mtd0 未变

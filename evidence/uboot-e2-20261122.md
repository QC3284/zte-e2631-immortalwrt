## 5. 真机验收（下一步，另排会话；零 flash 写）

按 [README §5.4](../uboot-port/README.md)：装载同 A1（厂商控制台 `tftp 0x47F00000 u-boot.bin` + `go`），
然后 `e2631net` → `mii info`（PHY 10-13，lan1=0x0c）→ `dhcp` → `ping <host>` →
`tftp 0x43000000 <file>`（**不要用 arena 0x45000000**）→ `e2631verify`；串口日志落盘并汇报 Lead。
失败定位顺序见 README §5.4 与设计文档 §7。

## 6. 风险 / 边界

- 单口 lan1；lan2/lan3/wan 走内核；PHY 0x14 fixup 与多口留 M2。
- 轮询 TX/RX、无中断：大文件 TFTP 占 CPU，仅用于救砖/更新。
- arena 固定地址：改地址必须同时改 `zx279128s_eth.h` 与 `e2631flash.c`，否则 CI 形状门禁失败；
  `e2631flash` 的 bounce buffer `0x44000000`+1 MiB 与 arena 边界有编译期断言。
- `e2631net` 的 `U_BOOT_CMD` 在 `drivers/net/`，不在板级静态 dump `E2631-COMMAND-HELP.txt` 的
  board-only 范围内；usage 原文：`"print the zx279128s Ethernet state"`（主行）+ 无子命令。二进制字符串门禁已覆盖。
- 回滚：E2 三个 patch 可逆序 revert（0018 的共享头被 0019/0020 依赖）；A5/A6 时钟/GPIO 与 e2631boot 启动路径不变。
